# data

Video verileri burada tutulur.

- `cams/`: projenin kullandigi 20 FPS kamera videolari
- `raw/`: gerekirse orijinal ham videolar
- `samples/`: hizli deneme icin kisa video kesitleri
- `vehicle_dataset/`: YOLO11s fine-tuning goruntuleri, etiketleri ve sinif tanimi

Standart calisma dosyalari:

```text
data/cams/camA_20fps.mp4
data/cams/camB_20fps.mp4
```

Medya dosyalari buyuk oldugu icin Git'e eklenmemelidir.
